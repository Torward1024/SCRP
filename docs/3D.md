# Optional 3D modules and C17 interface

`SCRP::Physics3D` and `SCRP::Render3D` are opt-in C++17 implementations with a
C17-compatible public interface in `include/scrp/c/`. They introduce no game
rules. Existing SDL_Renderer consumers keep their presentation path and do not
download Jolt when physics is disabled.

```sh
cmake -S . -B build/3d -DSCRP_WITH_PHYSICS3D=ON -DSCRP_WITH_RENDER3D=ON
cmake --build build/3d
ctest --test-dir build/3d --output-on-failure
```

Physics needs CMake 3.20 or newer. Render3D requires SDL2 and OpenGL 3.3 core.
`SCRP_TEST_RENDER3D=ON` adds the native OpenGL lifecycle test; it needs a real
graphics context and cannot use SDL's dummy video driver. Headless physics tests
need no SDL or GPU. Link a C application's final executable with the C++ linker.
The public headers contain no C++, SDL, OpenGL or Jolt types.

## Ownership and coordinates

- Initialize owning output pointers to NULL. Failed creation leaves them unchanged.
- Destroy takes a pointer to the owning handle and clears it; NULL is safe.
- Worlds own bodies; views own meshes. IDs are process-unique and checked against
  their owner. Removed IDs and IDs from another owner are rejected.
- Use each owner on one thread. Render3D belongs on the main thread. Do not use
  an owner after destroying it or initialize a second copy of Jolt in the process.
- Operations return 1 for success and 0 for failure, with an optional caller-owned
  error buffer. Exceptions are contained by the C boundary. Memory exhaustion
  inside the external physics backend is not a recoverable simulation guarantee.
- Units are meters, kilograms, seconds and radians. Coordinates are right-handed,
  with Y up. Quaternions use XYZW and must be unit length. Math and pose interpolation
  live in Core; interpolated poses use the shortest quaternion path.

## Physics

Jolt 5.3.0 is pinned to `0373ec0dd762e4bc2f6acdb08371ee84fa23c6db` and its archive
SHA256 is checked by CMake. Source and build outputs stay in the build dependency
cache. `FETCHCONTENT_SOURCE_DIR_JOLT` is an explicit development/offline override;
it must contain that same source revision. `FETCHCONTENT_FULLY_DISCONNECTED=ON`
requires an already populated dependency cache. See the [Jolt MIT notice](../licenses/Jolt-MIT.txt).

The initial API supplies static/dynamic boxes, shape-derived inertia, gravity,
forces and impulses at world points, teleport/reset, state queries, sleeping,
optional continuous collision detection and closest-hit rays with surface normals
and point velocity. A world has bounded capacity and uses a single-thread job
system. The default contact slop is 2 mm. No worker thread is created per body.

Apply forces, step once, then read the new state. A step must be in
`0.000001..1/30` second; fixed 120 Hz is a consumer choice. A force is consumed by
the next step, while an impulse changes velocity immediately. Static bodies ignore
forces/impulses. Teleport resets velocities and accumulated forces. An update
capacity error may occur after partial simulation; stop the caller's run on error.

Input limits protect the backend: box half-extents `0.01..10000`, dynamic mass
`0.001..1e8` (zero is static), friction `0..2`, restitution `0..1`, damping `0..10`,
position/ray components within `+/-1e6`, gravity components within `+/-1e4`,
force/impulse components within `+/-1e9`. A world supports `2..65536` bodies.
These are API limits, not accuracy guarantees for extreme scales.

Constraints, contact-event/impulse streams, convex sweeps, shape catalogues and
serialization are future extensions. Suspension, tires, drivetrain and collision
damage policies belong in consumers. No Jolt vehicle implementation is exposed.

## Presentation

A view owns an SDL OpenGL window/context, shader, mesh buffers and overlay stream.
The module provides perspective cameras, triangle meshes, box/cylinder primitives,
per-vertex colors, directional lighting, two generic spotlights and distance fog.
Draw scene meshes first, then the overlay. `present` optionally captures the back
buffer as BMP before swapping. The existing MicroFont glyph masks are shared with
the HUD, without creating an SDL_Renderer in an OpenGL window.

Mesh upload copies caller data. Drawing accepts a pose, positive XYZ scale, tint
and emissive factor. Polling reports elapsed time, focus and window close events;
key queries take SDL physical key names. Action bindings remain consumer policy.
The current renderer has no texture/material catalogue, shadows, mesh deformation,
resource streaming or postprocessing. It is a foundation for those facilities.

## Validation

C translation units exercise falling/resting bodies, equal gravitational
acceleration at different masses, off-center impulses, reset, rays, ownership,
invalid values and continuous collision through a thin floor. Native OpenGL tests
cover context coexistence, mesh ownership, frame order and overlay drawing.
Core and the existing SDL suites remain independent of these opt-in dependencies.
